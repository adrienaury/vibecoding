# VibeCoding

Ce dépôt rassemble mes petits projets web pour tester des idées, explorer des concepts et partager des démonstrations simples.

## Projets

| Projet | Description |
|--------|-------------|
| **IRRViz** | Mini-application web statique pour visualiser et explorer une idée autour de l'IRR, avec une interface simple et directe. |
| **IRRViz2** | Seconde version d'IRRViz, plus complète et plus ergonomique (TRI au survol, indicateurs, annuler / rétablir, import CSV avec aperçu, thèmes, mobile). Même stack : site statique + localStorage. |
